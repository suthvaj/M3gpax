# ระบบตรวจสอบคุณสมบัติและผลการเรียนสำหรับการรับนักเรียนเข้าศึกษาต่อ ม.4 ปีการศึกษา 2570
## ประเภทโควตา โรงเรียนมัธยมประชานิเวศน์

ระบบตรวจสอบข้อมูลส่วนบุคคลและผลการเรียนเฉลี่ยสะสม 5 ภาคเรียน (GPAX) สำหรับนักเรียนระดับชั้นมัธยมศึกษาปีที่ 3 เดิม ที่ประสงค์ยื่นขอรับการพิจารณาคุณสมบัติเข้าศึกษาต่อชั้นมัธยมศึกษาปีที่ 4 ปีการศึกษา 2570 ประเภทโควตา โรงเรียนมัธยมประชานิเวศน์

### โครงสร้างคอลัมน์ข้อมูลนักเรียน 9 รายการ (ตรงตามไฟล์ Excel โรงเรียน)

| ลำดับ | ชื่อคอลัมน์ | รายละเอียด |
|---|---|---|
| 1 | `เลขประจำตัว` | เลขประจำตัวนักเรียน 5 หลัก (จัดเก็บเป็น String รักษาเลข 0 ข้างหน้า) |
| 2 | `คำนำหน้า` | เด็กชาย, เด็กหญิง, นาย, นางสาว |
| 3 | `ชื่อ` | ชื่อนักเรียน |
| 4 | `นามสกุล` | นามสกุลนักเรียน |
| 5 | `GPAX` | เกรดเฉลี่ยสะสม 5 ภาคเรียน (ม.1 - ม.3 เทอม 1) |
| 6 | `เลขบัตรประชาชน` | เลขประจำตัวประชาชน 13 หลัก (String) |
| 7 | `คณิต` | เกรดเฉลี่ยกลุ่มสาระการเรียนรู้คณิตศาสตร์ |
| 8 | `วิทย์` | เกรดเฉลี่ยกลุ่มสาระการเรียนรู้วิทยาศาสตร์ |
| 9 | `ภาษาต่างประเทศ` | เกรดเฉลี่ยกลุ่มสาระการเรียนรู้ภาษาต่างประเทศ |

### ฟังก์ชันเด่นของระบบ

1. **ระบบสำหรับนักเรียน (Student Portal)**
   - ตรวจสอบผ่านเลขประจำตัวประชาชน 13 หลัก
   - ระบบจัดรูปแบบตัวเลขและขีดคั่นอัตโนมัติ (X-XXXX-XXXXX-XX-X)
   - ป้องกันการสุ่มค้นหาด้วย Rate Limiting และ Brute-force Prevention
   - แสดงผลในรูปแบบ Modern Personal Dashboard:
     - ส่วนที่ 1: ข้อมูลนักเรียน (ชื่อ-นามสกุล, รหัสนักเรียน, เลขบัตรประชาชนแบบปกปิด)
     - ส่วนที่ 2: GPAX 5 ภาคเรียน การ์ดขนาดใหญ่ เด่นชัด พร้อมสถานะการพิจารณา
     - ส่วนที่ 3: ผลการเรียนเฉลี่ยรายวิชา (คณิตศาสตร์, วิทยาศาสตร์, ภาษาต่างประเทศ)
     - ส่วนที่ 4: ข้อมูลและเงื่อนไขเพิ่มเติม พร้อมรหัสอ้างอิงเอกสาร
   - ปุ่มพิมพ์ใบรายงานผลการตรวจสอบ (Print / PDF Slip) พร้อมพื้นที่ลงนามทางการ

2. **ระบบผู้ดูแลระบบ (Admin Dashboard)**
   - เข้าสู่ระบบด้วย Google Workspace (Google Drive & Sheets) หรือ บัญชีผู้ดูแล
   - บัญชีทดสอบเริ่มต้น: `admin` / รหัสผ่าน: `pracha2570`
   - แดชบอร์ดสถิติภาพรวมและการกระจายตัวของเกรดเฉลี่ยสะสม
   - ระบบจัดการข้อมูลนักเรียน (เพิ่ม, แก้ไข, ลบ, ค้นหา, แบ่งหน้า)
   - ระบบตรวจสอบความถูกต้องของข้อมูล (Data Quality Audit): ตรวจจับเลขบัตรซ้ำ, รหัสซ้ำ, ข้อมูลไม่ครบ 13 หลัก, เกรดเฉลี่ยนอกช่วง 0.00-4.00
   - การเชื่อมต่อ Google Sheets API และ Google Drive แบบ 1-Click
   - บันทึกประวัติการค้นหา (Search Logs) โดยปกปิดเลขบัตรประชาชนตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)

### วิธีการนำไปติดตั้งใช้งาน (Deployment Guide)

#### ขั้นตอนที่ 1: เตรียม Google Sheets และ Google Apps Script
1. เข้าไปที่ [Google Drive](https://drive.google.com)
2. สร้าง Google Spreadsheet ใหม่ หรือกดปุ่ม "สร้าง Google Sheet ใหม่ใน Drive" จากหน้า Admin Dashboard ของระบบ
3. ใน Google Spreadsheet ให้ไปที่เมนู **ส่วนขยาย (Extensions)** &rarr; **Apps Script**
4. คัดลอกโค้ดจากไฟล์ `/gas/Code.gs` ไปวางในตัวแก้ไข Apps Script
5. เลือกฟังก์ชัน `setupDatabase` แล้วกด **เรียกใช้ (Run)** เพื่อสร้างชีต Students, SearchLogs, ActivityLogs อัตโนมัติ
6. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** &rarr; **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
7. เลือกประเภทเป็น **เว็บแอป (Web app)** กำหนดผู้มีสิทธิ์เข้าถึงเป็น **ทุกคน (Anyone)** แล้วกด Deploy

#### ขั้นตอนที่ 2: เผยแพร่เว็บไซต์บน Netlify
1. เชื่อมต่อ Git Repository เข้ากับ Netlify
2. ตั้งค่า Build Command: `npm run build`
3. ตั้งค่า Publish Directory: `dist`
4. เมื่อ Deploy สำเร็จ สามารถเข้าใช้งานเว็บไซต์ได้ทันที
